# Skillosophy skill library

**600 actual skill folders**, with source revisions, preserved licenses, supporting resources and file hashes. The original 17 plugin workflows are in [`../skills`](../skills).

This is a growing curation and revision library. Twelve entries have authored Skillosophy entrypoints; the remaining entries preserve upstream versions. Neither group is represented as universally improved or fully behaviorally tested. Inspect `skillosophy.json` in each folder for attribution/status. `UPSTREAM.md` preserves the baseline for authored revisions.

## Find and install a purposeful selection

```sh
python3 scripts/library/select.py search "React frontend keyboard accessible bulk edit" --domain frontend --limit 8
python3 scripts/library/select.py inspect senior-frontend
python3 scripts/library/select.py install --project /absolute/project --skill senior-frontend --review-note "Actual source, license, resources and compatibility review findings"
```

Run from the repository root. Installation previews by default; add `--apply` after source review when project setup is authorized. Inspect relevant resources and helper code first; discovery does not execute helpers. Missing entrypoint resource links block installation. Hashes are rechecked before writes; existing modified skills are preserved. Role documents are instructions, not launched/configured agents.

Search uses BM25-style lexical relevance over metadata; it loads zero skill bodies. Scores describe keyword fit, not performance. Use `--domain` to restrict a capability shortlist, or `route --brief` with a JSON object containing `goal` and `capabilities: [{"domain": "frontend", "task": "..."}, ...]`. Use focused queries for each project capability, compare actual task fit and prerequisites, then install a small selection. The plugin can also search the live community directory; generic public keywords only.
