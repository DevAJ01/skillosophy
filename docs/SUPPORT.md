# Skillosophy support

Skillosophy is a free project-start plugin published by Ashan Jeevanathan. It helps Codex users select and install useful skills and define specialist role instructions.

For help, feedback, or bugs, [open a GitHub issue](https://github.com/DevAJ01/skillosophy/issues/new). Include your plugin version, operating system, client version, intended task, and the actual error. A small reproducible example is useful.

GitHub issues are public. Remove credentials, confidential project files, and personal information before posting. Describe the problem without uploading your project where possible. GitHub manages accounts and issue storage under its own policies.

Installing a skill copies its files; it does not install runtime prerequisites, connect services, execute downloaded helpers, or register running subagents. If an upstream skill needs an external service or dependency, check its instructions separately.

Support is through the public issue tracker. No guaranteed response time or service-level agreement is offered.
