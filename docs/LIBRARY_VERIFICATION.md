# Library discovery and reviewed installation — 0.3.0

The packaged index contains 180 skill metadata entries pinned to seven public upstream repositories: OpenAI, Anthropic, Vercel, Supabase, Remotion, Obra's Superpowers, and Microsoft Azure Skills. It includes exact names, descriptions, paths, revisions, source links, and evidence states. It is a discovery library; all 180 packages have not been individually reviewed or benchmarked.

Live keyword search uses the skills.sh search protocol from the official [Skills CLI source](https://github.com/vercel-labs/skills/blob/main/src/find.ts), without installing or running that CLI. A real `react performance` query returned community matches and install counts. Counts are labeled popularity, not success. Non-GitHub results are unsupported by this installer. There is no claim to index every skill on the internet, and no assumption that the community endpoint is a stable public API.

Source inspection resolves immutable GitHub revisions, validates archive paths, preserves applicable licenses and notices, exposes instructions and file inventory, and records file hashes. Reviewed catalog extensions are separate from raw discovery results. Installation checks those hashes again before project mutation and maps catalog IDs to real invocation names in role documents.

Thirty-three integration checks passed: the earlier 18 installer cases and 15 discovery/review cases. New coverage includes metadata pinning, multi-line descriptions, ambiguous names, community source filtering, offline search, explicit network failures, root license/notice preservation, missing licenses and local dependencies, edited inspections, inspected-source installation, changed downloaded files, dependency validation, and real specialist-role invocation names.

A real Vercel React inspection refused installation because the pinned source had an MIT frontmatter declaration but no applicable license file. This conservative limit remains explicit; the tool does not invent a missing notice. A real Supabase PostgreSQL inspection found the root MIT license, 37 skill files, and no unresolved entrypoint Markdown links. The [independent forward trial](../evals/results/library-start/REPORT.md) used a hypothetical inventory API project: live search returned 19 candidates; the agent read the pinned Supabase entrypoint, all Markdown references, changelog and MIT license, then installed three local skills and wrote three specialist roles. All 41 receipt file hashes matched; original project instructions were preserved. It did not implement the API, execute SQL, connect accounts or run agents. No query speedup was claimed.

Review means an agent inspected source and requirements; it is not a security certification, legal attestation, or performance benchmark. Source instructions remain untrusted until assessed. External runtime setup and live database correctness are outside these installation checks.
