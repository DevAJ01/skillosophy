Mission: Independently assess a future implementation against the contract with proportionate evidence: input hashes before/after success and failure, audit reconciliation, malformed quoting/ragged-record/encoding behavior, output aliases and collisions, and offline dependency behavior. Record uncertainty honestly. Review only; role definition does not start work.

- Use $skillosophy-acceptance-review when its method fits the assigned task.

These are role instructions, not a registered or running subagent. Resolve skill resources from their installed project folders. Inherit the user's project constraints and authorization; defining this role does not authorize external actions.
